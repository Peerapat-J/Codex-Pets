## ไฟล์ใช้งาน

- [pet.json](pet.json): ID `mira`, ชื่อ `Mira`, `spriteVersionNumber: 2`
- [spritesheet.webp](spritesheet.webp): ภาพโปร่งใสขนาด 1536 × 2288 พิกเซล ช่องละ 192 × 208 พิกเซล
- [brief.json](brief.json): รายละเอียดรูปลักษณ์และลำดับ animation

ติดตั้งโดยนำ `pet.json` และ `spritesheet.webp` ไปไว้ด้วยกันใน `~/.codex/pets/mira/` หากมี Mira อยู่แล้ว ให้เก็บสำเนาเวอร์ชันเดิมก่อนแทนที่ จากนั้นเลือก Mira จากตัวเลือก pet ใน Codex เมื่อมีให้ใช้งาน

## Animation

เลขแถวและคอลัมน์เริ่มจาก 0

| แถว | State | จำนวนเฟรม |
| --- | --- | --- |
| 0 | idle | 6 |
| 1 | running-right | 8 |
| 2 | running-left | 8 |
| 3 | waving | 4 |
| 4 | jumping | 5 |
| 5 | failed | 8 |
| 6 | waiting | 6 |
| 7 | running — เปิดแฟ้มทำงาน | 6 |
| 8 | review | 6 |
| 9 | มอง 000° ถึง 157.5° | 8 |
| 10 | มอง 180° ถึง 337.5° | 8 |

Neutral frame อยู่แถว 0 คอลัมน์ 6 ส่วนช่องที่ไม่ได้ใช้โปร่งใส ทิศการมองเริ่มที่ 000° = ด้านบน และหมุนตามเข็มนาฬิกาทีละ 22.5°

## ผลตรวจ

Atlas ผ่านการตรวจ v2 ทั้งโครงสร้างและความโปร่งใส การตรวจภาพเคลื่อนไหวแยกอิสระผ่านครบทุกแถว และผู้ตรวจแบบไม่เห็นชื่อทิศ 3 คนยืนยันทิศหลักทั้งสี่ผ่านเกณฑ์รวม

ท่ามองขึ้นบริเวณ 292.5°, 315° และ 337.5° มีการเงยที่ค่อนข้างละเอียด โดย 315° มีความกำกวมระดับเล็กน้อยที่ยอมรับจากการตรวจภาพพร้อมป้ายกำกับ การเลือก Mira ใช้งานจริงใน Codex UI ยังไม่ได้ทดสอบ

## แนวทางภาพ

สร้างด้วยเครื่องมือ `image_gen` แล้วประกอบและตรวจ atlas ด้วย `hatch-pet` ใช้ภาพอนิเมะ 2D แบบ cel shading เส้นคม สัดส่วนตัวเล็กเต็มตัว และแฟ้มเล่มเดียวเพื่อให้อ่านรูปทรงได้ที่ขนาด pet ใบหน้า ผม แว่น สีชุด และตำแหน่งแฟ้มต้องต่อเนื่องระหว่างเฟรม
